What's available today

  • Assessment Report Builder — build a branded PDF report from findings, in your browser. Open it →
  • Free security tools — password generator, strength checker, security headers / SSL / website checks. Browse tools →

Everything else in these docs (dashboard, endpoints, alerts, API) is in design and marked soon.

Using the Report Builder

  1. Open the Report Builder.
  2. Fill in the engagement details: client, type, date, reference, assessor, scope.
  3. Write an executive summary for leadership.
  4. Click Add finding for each issue. Set severity, likelihood, and impact, then describe the finding and your recommendation.
  5. Watch the risk matrix and severity summary update live.
  6. Click Generate PDF report to download a branded, confidential PDF.

Use Save to export the engagement as a JSON file, and Load to bring it back later. Your work also auto-saves in the browser.

Where your data lives

The Report Builder runs entirely in your browser. Findings and client data are never uploaded — they stay on your device (and in the PDF you download). This is deliberate: client assessment data is sensitive and should not sit on someone else's server without need.
