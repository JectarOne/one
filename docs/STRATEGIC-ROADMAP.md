# JectarOne — Strategic Roadmap

> Build a trusted Moroccan cybersecurity company first; become a SaaS platform second.

This consolidates the company's strategic and execution roadmaps into a single reference.

## Vision

Become one of the leading cybersecurity companies in Morocco and North Africa by combining expert consulting with practical software products.

## Mission

Help Moroccan businesses improve their cybersecurity through clear assessments, actionable recommendations, and affordable security solutions.

## Business model (3 phases)

1. **Consulting** — revenue from cybersecurity consulting services.
2. **Internal tools** — build tools that improve consulting efficiency.
3. **SaaS** — turn proven tools into subscription products.

---

## Execution roadmap

### Phase 1 — Credible company website ✅ (in progress)
Essential pages live: Home, About, Services, Case Studies (demo), Blog, Contact, Privacy Policy, Terms of Service.

### Phase 2 — Professional identity
- Professional email (`contact@jectar.one`) ✅
- LinkedIn Company Page
- Google Business Profile
- SVG logo
- Company Profile (PDF) — derive from [COMPANY-PROFILE.md](COMPANY-PROFILE.md)

### Phase 3 — Focused services
Core offering centered on Vulnerability Assessment, Web Application Penetration Testing, and SME Security Audit, each with a clear "Request a Quote" path. ✅ (service pages live)

### Phase 4 — Build trust through content
No fake logos, testimonials, or statistics. Publish practical technical articles. ✅ (first 4 articles live) — see [CONTENT-STRATEGY.md](CONTENT-STRATEGY.md).

### Phase 5 — Free security tools
Practical utilities that attract organic traffic:
- Password Generator
- Password Strength Checker
- Security Headers Checker
- SSL Certificate Checker
- Website Security Scanner

> **Build note:** Password Generator, Password Strength Checker, and a GDPR Cookie checker are fully client-side (static). Security Headers, SSL, and Website Scanner require a backend or proxy (CORS) — plan a small serverless function for these.

### Phase 6 — Small SaaS (MVP)
One focused product, done well. Candidates: Client Portal, Assessment Dashboard, PDF Report Generator, Risk Matrix.

## Product roadmap (SaaS)

| Release | Features |
|---------|----------|
| **MVP** | Client Portal · Assessment Dashboard · PDF Report Generator · Risk Matrix |
| **v2** | Asset Inventory · Vulnerability Tracking · Remediation Tasks · Team Collaboration |
| **v3** | Continuous Monitoring · Integrations · Executive Dashboards · Customer API |

> Do not build a platform like Wiz or CrowdStrike. Solve one problem exceptionally well.

## Go-to-market

- **Year 1** — launch website, publish technical articles, network locally, acquire first 10 customers. *(Consulting-led revenue.)*
- **Year 2** — release MVP SaaS, build recurring revenue, publish case studies. *(Consulting + subscriptions.)*
- **Year 3** — expand across Morocco, then enter North African markets. *(Growing SaaS recurring revenue.)*

---

## Success metrics

- First paying customer
- First recurring client
- 10 completed assessments
- 1,000 monthly website visitors
- First SaaS subscribers
- Expansion beyond Morocco

## Long-term vision (2030)

JectarOne evolves from a respected Moroccan cybersecurity consultancy into a regional cybersecurity software company serving North Africa and French-speaking Africa with practical, reliable security products.
